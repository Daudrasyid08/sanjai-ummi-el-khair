# Sanjai Ummi El Khair

Website foundation for Sanjai Ummi El Khair, a family-run Indonesian snack and souvenir business in Padang Panjang, West Sumatra.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available commands

```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Project structure

- `src/app` — App Router routes, global styles, and metadata
- `src/components` — reusable UI components
- `public` — static assets

The initial route is intentionally content-free. Homepage design, business details, product content, and commerce features have not been added.
